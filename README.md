# VidaFit

🔗 [Acesse o projeto aqui](https://nadjaamaria.github.io/vidafit-Atividade4/)

---

## 🧩 Descrição
O **VidaFit** é um projeto de site voltado para **treinos, saúde e bem-estar**, com páginas de **Início, Treinos e Cadastro**.  
O objetivo é desenvolver uma aplicação web **funcional, responsiva e acessível**, utilizando **HTML5, CSS3 e JavaScript**, aplicando boas práticas de **desenvolvimento, versionamento e acessibilidade**.

---

## 🧠 Tecnologias Utilizadas
- **HTML5** – Estrutura semântica do site.  
- **CSS3** – Estilização e design responsivo.  
- **JavaScript** – Interatividade (menu e formulário).  
- **Font Awesome** – Ícones utilizados na interface.  
- **Git/GitHub** – Controle de versão e hospedagem.  

---

## ⚙️ Funcionalidades
- **Menu Responsivo:** Menu hambúrguer para dispositivos móveis.  
- **Página de Início:** Apresenta o VidaFit com destaque visual e botão “Começar Agora”.  
- **Página de Treinos:** Cards com diferentes modalidades de treino (Força, Flexibilidade, Cardio, Yoga, Pilates, HIIT, Circuito).  
- **Página de Cadastro:** Formulário com validação e mensagem de sucesso após o envio.  
- **Acessibilidade:** Estrutura semântica, contraste adequado e navegação por teclado.  
- **Responsividade:** Layout adaptável para diversos tamanhos de tela.  
- **Interatividade:** Funcionalidades dinâmicas com JavaScript, garantindo uma boa experiência do usuário.
